One emoji for one dream vacation: 🛖 — a hut over the water, the overwater bungalow. A single glyph that is the whole postcard: turquoise lagoon, stilt house, nowhere else to be. Entry for make.fun's "One Emoji, One Dream Vacation" bounty ($2 in USDC, winner takes all). The judge reads entries two at a time and picks the one that most makes a stranger want to book the flight.

## Run it

```sh
node main.ts
```

The program writes exactly one emoji to `/output/entry.txt` (set `OUTPUT_DIR` to redirect it locally). No network, no randomness, no model calls — the output is byte-identical on every run.
